## 1. JDBC

### JDBC란?

Java에서 데이터베이스에 접근하기 위한 표준 API이다.

Spring Boot에서는 JDBC를 이용해 데이터베이스와 연결하고 SQL을 실행할 수 있다.

### Connection Pool

데이터베이스 연결을 매번 생성하고 종료하는 대신 미리 여러 개의 Connection을 생성해두고 재사용하는 방식이다.

Spring Boot에서는 기본적으로 **HikariCP**를 사용할 수 있다.

### Repository

`CrudRepository`를 상속하면 기본적인 CRUD 기능을 제공받을 수 있다.

```java
public interface MemberRepository extends CrudRepository<Member, Long> {
}
```

주요 메서드:

| 기능    | 메서드                           |
| ----- | ----------------------------- |
| 저장/수정 | `save()`                      |
| 단건 조회 | `findById()`                  |
| 전체 조회 | `findAll()`                   |
| 삭제    | `deleteById()`, `deleteAll()` |
| 전체 개수 | `count()`                     |

### Query Method

메서드 이름을 규칙에 맞게 작성하면 조건에 맞는 조회 기능을 만들 수 있다.

```java
List<Member> findByName(String name);

Member findByEmail(String email);

List<Member> findByAgeGreaterThan(Integer age);

List<Member> findByNameAndEmail(String name, String email);
```

예를 들어:

```java
findByAgeGreaterThan(20)
```

→ 나이가 20보다 큰 회원 조회

```java
findByNameAndEmail("윤광철", "Kwang@hanbit.co.kr");
```

→ 이름과 이메일이 모두 일치하는 회원 조회

### CRUD 실습

* `save()`를 이용한 회원 저장
* 저장된 객체의 값 변경 후 다시 `save()`하여 수정
* `findAll()`, `findById()`를 이용한 조회
* 조건에 따른 회원 조회
* `deleteById()`를 이용한 삭제

## 2. MyBatis

### MyBatis란?

SQL을 직접 작성하면서 Java 객체와 데이터베이스를 연결할 수 있도록 도와주는 SQL Mapper 프레임워크이다.

JDBC처럼 SQL을 직접 제어하면서도 반복적인 JDBC 코드를 줄일 수 있다.

### Mapper

MyBatis에서는 Mapper 인터페이스를 통해 SQL을 호출한다.

```java
@Mapper
public interface MemberMapper {

    List<Member> selectAll();

    Optional<Member> selectById(@Param("id") Long id);

    Optional<Member> selectByEmail(@Param("email") String email);

    List<Member> selectByNameLike(@Param("name") String name);

    int insert(@Param("member") Member member);

    int update(@Param("member") Member member);

    int delete(@Param("member") Member member);

    int deleteById(@Param("id") Long id);

    int deleteAll();
}
```

`@Mapper`를 사용하면 MyBatis가 해당 인터페이스를 Mapper로 등록한다.

### XML Mapper

SQL을 XML 파일에 작성할 수도 있다.

```xml
<mapper namespace="com.example.demo.mapper.MemberMapper">

    <select id="selectAll">
        SELECT * FROM member
    </select>

    <select id="selectById">
        SELECT * FROM member WHERE id=#{id}
    </select>

    <select id="selectByNameLike">
        SELECT * FROM member WHERE name LIKE #{name}
    </select>

</mapper>
```

`namespace`는 Mapper 인터페이스의 전체 경로와 일치해야 한다.

```text
com.example.demo.mapper.MemberMapper
```

XML의 `id`는 Mapper 인터페이스의 메서드 이름과 연결된다.

```text
selectAll → selectAll()
selectById → selectById()
insert → insert()
```

### Mapper XML 위치

```text
src/main/resources/mapper/MemberMapper.xml
```

`application.properties`에서 Mapper XML 위치를 설정할 수 있다.

```properties
mybatis.mapper-locations=classpath:mapper/*.xml
```

### Parameter 전달

Mapper 메서드에서 `@Param`을 사용하면 XML에서 이름으로 파라미터를 사용할 수 있다.

```java
int insert(@Param("member") Member member);
```

XML:

```xml
<insert id="insert">
    INSERT INTO member(name, email, age)
    VALUES(#{member.name}, #{member.email}, #{member.age})
</insert>
```

### 자동 생성된 ID 받기

`useGeneratedKeys`를 사용하면 INSERT 후 생성된 ID를 객체에 넣을 수 있다.

```xml
<insert id="insert">
        useGeneratedKeys="true"
        keyProperty="member.id"
        keyColumn="id"
</insert>
```

## 3. MyBatis 어노테이션 방식

XML을 사용하지 않고 Mapper 인터페이스에 SQL을 직접 작성할 수도 있다.

```java
@Mapper
public interface ArticleMapper {

    @Select("SELECT * FROM article")
    List<Article> selectAll();

    @Select("SELECT * FROM article WHERE id = #{id}")
    Optional<Article> selectById(@Param("id") Long id);
}
```

### XML 방식 vs 어노테이션 방식

| 방식         | 특징                        |
| ---------- | ------------------------- |
| XML Mapper | SQL과 Java 코드를 분리할 수 있음    |
| 어노테이션      | 간단한 SQL을 인터페이스에서 바로 작성 가능 |

SQL이 복잡해질수록 XML 방식이 관리하기 편하다.

## 4. JDBC와 MyBatis 비교

| 구분           | JDBC      | MyBatis              |
| ------------ | --------- | -------------------- |
| SQL 작성       | 직접 작성     | 직접 작성                |
| 반복 코드        | 많음        | 줄어듦                  |
| SQL과 Java 분리 | 어려움       | XML 사용 시 가능          |
| 객체 매핑        | 직접 처리     | MyBatis가 지원          |
| CRUD         | 직접 구현     | Mapper로 관리           |
| 특징           | 저수준 DB 접근 | SQL 중심의 Mapper 프레임워크 |

### 핵심

```text
JDBC
→ Java에서 DB 연결과 SQL 실행을 직접 관리

MyBatis
→ SQL은 직접 작성하지만
  JDBC의 반복적인 작업과 객체 매핑을 줄여줌
```
