## 1. 💉 Spring DI

### Dependency Injection이란?

**DI(Dependency Injection, 의존성 주입)**는 객체가 필요한 의존 객체를 직접 생성하지 않고, **Spring 컨테이너가 객체를 생성하여 주입해 주는 방식**이다.

### 생성자 주입

```java
@Service
public class MemberService {

    private final MemberRepository memberRepository;

    public MemberService(MemberRepository memberRepository) {
        this.memberRepository = memberRepository;
    }
}
```

### 필드 주입

```java
@Service
public class MemberService {

    @Autowired
    private MemberRepository memberRepository;
}
```

### Setter 주입

```java
@Service
public class MemberService {

    private MemberRepository memberRepository;

    @Autowired
    public void setMemberRepository(MemberRepository memberRepository) {
        this.memberRepository = memberRepository;
    }
}
```

> 💡 일반적으로 **생성자 주입을 권장**한다.

# 2. 🔄 IoC

### IoC란?

**IoC(Inversion of Control, 제어의 역전)**는 객체의 생성과 관리에 대한 제어권을 개발자가 직접 가지는 것이 아니라 **Spring 컨테이너가 담당하는 것**이다.

```text
기존 방식

개발자
  ↓
new MemberService()
  ↓
객체 생성 및 관리


Spring

개발자
  ↓
Spring 컨테이너
  ↓
객체 생성 및 관리
  ↓
필요한 곳에 의존성 주입
```

### Bean

Spring 컨테이너가 생성하고 관리하는 객체를 **Bean**이라고 한다.

```java
@Component
public class MemberService {
}
```

`@Component`가 붙은 클래스는 Spring이 Bean으로 등록하여 관리할 수 있다.

# 3. 🏷️ Spring Annotation

## @Component

클래스에 사용한다.

Spring이 해당 클래스를 **Bean으로 등록하여 Spring 컨테이너에서 관리**할 수 있도록 한다.

```java
@Component
public class MemberService {

}
```

---

## @Autowired

의존성을 주입할 때 사용한다.

Spring이 필요한 Bean을 찾아 해당 위치에 주입한다.

```java
@Service
public class MemberService {

    private final MemberRepository memberRepository;

    @Autowired
    public MemberService(MemberRepository memberRepository) {
        this.memberRepository = memberRepository;
    }
}
```

> 💡 생성자가 하나뿐인 경우 Spring에서는 `@Autowired`를 생략할 수 있다.

```java
@Service
public class MemberService {

    private final MemberRepository memberRepository;

    public MemberService(MemberRepository memberRepository) {
        this.memberRepository = memberRepository;
    }
}
```

---

## @PostConstruct

Bean 생성 및 의존성 주입이 완료된 후 **초기화 작업을 수행할 때 사용**한다.

```java
@Component
public class MemberService {

    @PostConstruct
    public void init() {
        System.out.println("Bean 초기화 완료");
    }
}
```

실행 순서:

```text
Bean 생성
   ↓
의존성 주입
   ↓
@PostConstruct 실행
```

---

## @SpringBootApplication

Spring Boot 애플리케이션의 시작점이 되는 클래스에 사용한다.

```java
@SpringBootApplication
public class Application {

    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
```

`@SpringBootApplication`은 여러 설정을 하나로 묶은 애노테이션이다.

대표적으로:

```text
@Configuration
@EnableAutoConfiguration
@ComponentScan
```

을 포함한다.

특히 `@ComponentScan`을 통해 **해당 클래스가 위치한 패키지를 기준으로 하위 패키지의 Component들을 검색**한다.

---

## @ImportResource

Spring에서 사용하는 XML 설정 파일을 불러올 때 사용한다.

```java
@SpringBootApplication
@ImportResource("classpath:applicationContext.xml")
public class Application {

    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
```

XML에 정의된 Bean 설정을 Spring 컨테이너에 등록할 수 있다.

### XML 예시

```xml
<bean id="memberService"
      class="com.example.MemberService"/>
```

# 4. ⚡ AOP 관련 Annotation

## @Before

조인 포인트가 실행되기 **전에** 실행할 로직을 작성한다.

```java
@Before("@annotation(PrintExecutionTime)")
public void before() {
    System.out.println("메서드 실행 전");
}
```

```text
@Before
   ↓
실제 메서드 실행
```

---

## @After

조인 포인트가 실행된 **후에** 실행한다.

```java
@After("@annotation(PrintExecutionTime)")
public void after() {
    System.out.println("메서드 실행 후");
}
```

메서드가 정상적으로 종료되든 예외가 발생하든 실행되는 형태로 사용할 수 있다.

---

## @AfterReturning

메서드가 **정상적으로 실행되고 값을 반환한 후** 실행한다.

```java
@AfterReturning(
    pointcut = "@annotation(PrintExecutionTime)",
    returning = "result"
)
public void afterReturning(Object result) {
    System.out.println("반환값: " + result);
}
```

```text
메서드 실행
   ↓
정상적인 반환
   ↓
@AfterReturning
```

---

## @AfterThrowing

메서드 실행 중 **예외가 발생했을 때** 실행한다.

```java
@AfterThrowing(
    pointcut = "@annotation(PrintExecutionTime)",
    throwing = "ex"
)
public void afterThrowing(Exception ex) {
    System.out.println("예외 발생: " + ex.getMessage());
}
```

```text
메서드 실행
   ↓
예외 발생
   ↓
@AfterThrowing
```

# 5. 🛠️ Lombok Annotation

## @Data

클래스에 사용한다.

다음과 같은 기능을 한 번에 제공한다.

```text
@Getter
@Setter
@ToString
@EqualsAndHashCode
@RequiredArgsConstructor
```

예시:

```java
@Data
public class Member {

    private String name;
    private String email;
}
```

기존에는 다음과 같이 여러 애노테이션을 작성해야 할 수 있다.

```java
@Getter
@Setter
@ToString
@EqualsAndHashCode
@RequiredArgsConstructor
public class Member {

    private String name;
    private String email;
}
```

---

## @AllArgsConstructor

**모든 필드를 매개변수로 받는 생성자**를 만들어준다.

```java
@AllArgsConstructor
public class Member {

    private String name;
    private String email;
}
```

Lombok이 다음과 같은 생성자를 만들어준다.

```java
public Member(String name, String email) {
    this.name = name;
    this.email = email;
}
```

---

## @NoArgsConstructor

**매개변수가 없는 기본 생성자**를 만들어준다.

```java
@NoArgsConstructor
public class Member {

    private String name;
    private String email;
}
```

다음과 같은 생성자가 자동으로 만들어진다.

```java
public Member() {
}
```

---

## @RequiredArgsConstructor

`final` 또는 `@NonNull`이 붙은 필드를 매개변수로 받는 생성자를 만들어준다.

```java
@RequiredArgsConstructor
public class MemberService {

    private final MemberRepository memberRepository;
}
```

다음과 같은 생성자가 만들어진다.

```java
public MemberService(MemberRepository memberRepository) {
    this.memberRepository = memberRepository;
}
```

> 💡 Spring의 **생성자 주입 + Lombok**을 함께 사용할 때 자주 사용한다.

```java
@Service
@RequiredArgsConstructor
public class MemberService {

    private final MemberRepository memberRepository;
}
```

---

## @Builder

객체를 생성할 때 **Builder 패턴을 사용할 수 있도록** 해준다.

```java
@Builder
public class Member {

    private String name;
    private String email;
    private int age;
}
```

사용:

```java
Member member = Member.builder()
        .name("홍길동")
        .email("test@test.com")
        .age(20)
        .build();
```

### Builder 패턴

객체 생성 과정을 단계적으로 작성할 수 있어 **가독성을 높이고 복잡한 생성자 사용을 줄이는 데 도움**을 준다.

```java
Member member = Member.builder()
        .name("홍길동")
        .email("test@test.com")
        .age(20)
        .build();
```

---

## @Slf4j

클래스에 사용하면 Lombok이 `log`라는 로깅 객체를 자동으로 만들어준다.

```java
@Slf4j
public class MemberService {

    public void test() {
        log.info("회원 조회");
        log.debug("디버깅 정보");
        log.error("에러 발생");
    }
}
```

기존에 직접 Logger를 선언하는 작업을 줄일 수 있다.

```text
log.info()
log.debug()
log.warn()
log.error()
```

등을 사용할 수 있다.

---

## @EqualsAndHashCode

`equals()`와 `hashCode()` 메서드를 자동으로 생성해준다.

```java
@EqualsAndHashCode(of = {"name", "email"})
public class Member {

    private String name;
    private String email;
    private int age;
}
```

위와 같이 작성하면 `name`과 `email`을 기준으로 `equals()`와 `hashCode()`가 생성된다.

즉,

```java
Member member1 = new Member("홍길동", "test@test.com", 20);
Member member2 = new Member("홍길동", "test@test.com", 30);
```

두 객체의 `name`과 `email`이 같다면 `equals()` 비교에서 같다고 판단할 수 있다.

> ⚠️ `equals()`에서 어떤 필드를 기준으로 비교할지 신중하게 정해야 한다.

# 📌 오늘 핵심 정리

### Spring

```text
IoC
 ↓
Spring 컨테이너가 객체를 생성하고 관리
 ↓
Bean
 ↓
DI
 ↓
필요한 객체를 주입
```

### 주요 Annotation

| Annotation                 | 역할                    |
| -------------------------- | --------------------- |
| `@Component`               | Bean 등록               |
| `@Autowired`               | 의존성 주입                |
| `@PostConstruct`           | Bean 초기화 후 실행         |
| `@SpringBootApplication`   | Spring Boot 애플리케이션 시작 |
| `@ImportResource`          | XML 설정 불러오기           |
| `@Before`                  | 메서드 실행 전 AOP          |
| `@After`                   | 메서드 실행 후 AOP          |
| `@AfterReturning`          | 정상 반환 후 AOP           |
| `@AfterThrowing`           | 예외 발생 시 AOP           |
| `@Data`                    | 여러 Lombok 기능 제공       |
| `@AllArgsConstructor`      | 전체 필드 생성자             |
| `@NoArgsConstructor`       | 기본 생성자                |
| `@RequiredArgsConstructor` | 필수 필드 생성자             |
| `@Builder`                 | Builder 패턴 지원         |
| `@Slf4j`                   | Logger 자동 생성          |
| `@EqualsAndHashCode`       | equals/hashCode 자동 생성 |
