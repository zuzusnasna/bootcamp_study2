# 2026-09-10 학습 정리

## Spring Boot 배포 설정

오늘은 기존 게시판 프로젝트와 별도로 `deployment` 프로젝트를 생성하고, Spring Boot 애플리케이션을 **JAR/WAR 형태로 배포할 수 있도록 설정**했다.

### 1. Gradle WAR 플러그인 추가

`build.gradle`에 `war` 플러그인을 추가했다.

```gradle
plugins {
    id 'java'
    id 'war'
    id 'org.springframework.boot' version '4.1.1'
    id 'io.spring.dependency-management' version '1.1.7'
}
```

WAR(Web Application Archive)는 웹 애플리케이션을 서버에 배포할 때 사용하는 패키징 형식이다.

### 2. Spring Boot 버전 및 프로젝트 버전 설정

Spring Boot 버전을 `4.1.1`로 설정하고 프로젝트 버전을 `1.0.2`로 변경했다.

```gradle
version = '1.0.2'
```

### 3. Tomcat 의존성 설정

외부 Tomcat 환경에 배포할 수 있도록 Tomcat을 `providedRuntime`으로 설정했다.

```gradle
providedRuntime 'org.springframework.boot:spring-boot-starter-tomcat:4.1.1'
```

애플리케이션을 WAR로 만들어 외부 Servlet 컨테이너에서 실행할 때 필요한 설정이다.

---

## SpringBootServletInitializer

외부 Tomcat에서 Spring Boot 애플리케이션을 실행하기 위해 `ServletInitializer`를 추가했다.

```java
public class ServletInitializer extends SpringBootServletInitializer {

    @Override
    protected SpringApplicationBuilder configure(SpringApplicationBuilder application) {
        return application.sources(DemoApplication.class);
    }
}
```

기존의 `main()` 메서드로 직접 실행하는 방식과 별개로, 외부 Servlet 컨테이너가 Spring Boot 애플리케이션을 시작할 수 있도록 연결해주는 역할을 한다.

```text
외부 Tomcat
    ↓
ServletInitializer
    ↓
DemoApplication
    ↓
Spring Boot 애플리케이션 실행
```

## Profile을 이용한 개발 환경 초기화

`DataInitializer`를 생성하고 `@Profile("dev")`를 적용했다.

```java
@Component
@Profile("dev")
public class DataInitializer implements ApplicationRunner {
    // 초기 데이터 저장
}
```

`dev` 프로파일에서만 실행되도록 하여 개발 환경에서 필요한 초기 회원 데이터를 자동으로 저장하도록 구성했다.

```text
dev 프로파일
    ↓
DataInitializer 실행
    ↓
MemberRepository
    ↓
회원 초기 데이터 저장
```

## Member API 실습

`MemberController`를 만들고 회원 목록을 조회하는 API를 추가했다.

```java
@RestController
@RequiredArgsConstructor
public class MemberController {

    private final MemberRepository memberRepository;

    @GetMapping("/members")
    public List<Member> getMembers() {
        return memberRepository.findAll();
    }
}
```

`GET /members` 요청을 보내면 `MemberRepository.findAll()`을 통해 저장된 회원 목록을 조회할 수 있다.

## H2 개발 환경 설정

개발 환경과 테스트 환경을 분리하기 위해 프로파일별 H2 데이터베이스 설정을 추가했다.

### dev

```properties
spring.datasource.url=jdbc:h2:mem:devdb
spring.datasource.username=devu
spring.datasource.password=devp
spring.h2.console.enabled=true
```

### test

```properties
spring.datasource.url=jdbc:h2:mem:testdb
spring.datasource.username=testu
spring.datasource.password=testp
```

개발 환경과 테스트 환경에서 서로 다른 H2 데이터베이스를 사용하도록 구성했다.
